# 연구 평가 프로토콜

## 연구군

| 군 | 기대 행위 결정 | 목적 |
|---|---|---|
| A | 기능별 고정 규칙 | 규칙 기준선 |
| B | AI 기능 분류 + 고정 권한 매핑 | 분류 기여도 |
| C | AI 기능 분류 + 명시 행위·근거 추출 + 고정 정책 | 전체 제안 방식 |

추가 비교군으로 설치 스크립트 일괄 차단, 정적 시그니처, 모든 외부 행위를 위험 처리하는 일반 동적 탐지를 둡니다.

## 데이터 분할

1. 파일럿: 설치 스크립트 패키지 20~30개
2. 보정군: 참조 패키지 300개
3. 최종 평가군: 참조 패키지 300개
4. 동일 패키지의 다른 버전은 서로 다른 분할에 넣지 않음
5. 기능 유형과 사용 규모를 기준으로 층화

“정상” 대신 “알려진 악성 이력이 없는 참조 패키지”라고 기록합니다.

## 공격 시뮬레이션

- 가짜 SSH·AWS·npm 인증정보 읽기
- 카나리 환경변수 읽기
- 미선언 TEST-NET 연결
- 로컬 싱크홀 다운로드 후 무해 파일 실행
- 가짜 셸 시작 파일 수정
- 가짜 `/proc` 정보 탐색

각 유형에 평문, 문자열 분할, Base64, 동적 import, 백그라운드, 0·10·30·60·120초 지연을 적용합니다. 실제 비밀, 실제 C2, 호스트 홈은 사용하지 않습니다.

## 임계값 고정

보정군 점수의 99번째 백분위로 오탐률 1% 목표 임계값을 정합니다.

\[
\tau = Q_{0.99}(S_{calibration})
\]

최종 평가군 결과를 본 뒤 임계값이나 가중치를 다시 조정하지 않습니다.

## 지표

문서 분석:

- 기능 유형 Macro-F1
- 선언 행위 Precision·Recall·F1
- 근거 문장 정확도
- 반복 결과 일치율
- 위험 행위 오승인률
- 프롬프트 인젝션 우회 성공률

최종 탐지:

- 참조 패키지 오탐률
- 공격 시뮬레이션 탐지율
- 기능·공격 유형별 성능
- PR-AUC와 ROC-AUC
- 관측 시간별 탐지율
- 실행 시간·CPU·메모리 증가율

## 재현성 기록

- 패키지 이름·버전·무결성 해시
- 샌드박스 이미지 digest
- 정책 버전과 Git commit
- 분석기 공급자·모델·프롬프트 버전
- 관측 시간과 자원 제한
- 원시 로그 해시와 정규화 코드 버전
- 실험 시각과 운영체제·커널 정보
